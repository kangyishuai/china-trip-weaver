# ADR-0023：版本化旅程剖面候选

- **Status:** Adopted in local `main` after scoped independent experience acceptance on 2026-09-24. Publication is determined by the exact git tag and GitHub Release.
- **Date:** 2026-09-23

## Context

[ADR-0006](0006-single-deterministic-renderer.md) 定义了 v1 的无执行脚本单文件 Trip 页面。长 Journey 的日期、交通、住宿和核验项在旧页分散；隔离的 Victor 原型把路线、共同时间尺度、所选日上下文及可撤回的局部 +30 分钟试探放在同一阅读路径。用户早期真实截图揭示标题断字、焦点内部滚动和价格枚举外露；这些问题已按源数据修正，并在限定合成样本的后续体验验收中复核。

## Candidate decision

同一 `ctw render`／`ctw journey render` CLI 入口生成带 `data-renderer-version="2"` 和 `ctw-renderer` meta 的 v2。旧 v1 HTML 继续由原校验器按原合同验证。Python `render_trip(..., renderer_version="1")`／`render_journey(..., renderer_version="1")` 保留原公开调用与字节行为；v2 可显式传入 `renderer_version="2"`。CLI 与规划/重规划输出选 v2。没有第二个面向用户的 `explore` 命令。

v2 首屏是路线、优先决定、共同时间轴和所选日；在页面下方的“完整行程与来源记录”折叠区复用 **同一份 v1 渲染函数**输出的可读事实，不从 JSON 隐藏恢复。这样迁移期可逐项审查能力覆盖，避免复制运输、天气、餐饮、位置、预算、风险等生成逻辑。代价是 v2 页面较大，展开完整记录后会看到部分重复信息；限定合成样本的独立体验验收接受了这一取舍，不代表所有输入和设备均已通测。

获批的 C03 仅在 v2 折叠区把重复的 v1 页头与真实性横幅合成一块可读的“记录范围与真实性”摘要；其独有的修订/生成时间/数据模式、Trip 最弱数据源与未知数、Journey 段数与清单/风险数、条件 mock 提示仍直接可见。原 v1 导航、完整事实正文、footer 的免责声明与条件服务商署名、全部深链和 v1 HTML 合同保留。这是信息重复的局部减法；完整正文、来源和打印导航已在限定样本的实际产物中核对。

真实默认页截图的后续退修把 v2 主阅读顺序改为“首要核验决定→当天安排→全程时间图→按需原始依据”。源时段、未知、价型、已知费用和完整事实正文没有删除；次级决策与城市停留日期由原生展开控件取得，原始诊断按核验主题归组并在全程图后完整可读。样式与固定脚本字节变化同步更新 v2 草案资产摘要及黄金合成页；此设计已在本地 `main` 采用，正式发行以精确标签和 GitHub Release 为准，不暗示旧 v2 草案可由当前规范化 validator 通过。

交互脚本是插件 `assets/profile.js` 的固定版本字节。v2 CSP 仅放行该字节的 SHA-256，仍禁止默认资源、网络连接、表单、frame、object 与外部脚本；CSS 与源 JSON 都内联，离线单文件。校验器用受信插件资产和输入 JSON **重新确定性生成整个页面并逐字节比较**，还单独核对执行脚本与嵌入 source。这会拒绝脚本和 CSP 同时改写、伪造可见金额/时段、删来源或改链接。该合同刻意只接受本版本生成的规范化页面；人为重排空白也须重新生成。v1 的 E/JH 安全断言不因此放松。

v2 的资产摘要由现有 v1 共享 CSS、新 CSS、新 JS 组成，作为固定值留在插件源码并写入页面 `ctw-profile-assets` meta。同一格式下改变这些资产字节（即使只是 CSS 末尾换行）时，新生成直接拒绝；旧页校验明确报 `V207`，而非默默用新资产重解释旧页。单独的源事实检查 `V206` 从输入 Trip/Journey 直接核对页头日期、人数和天数，不以“页面等于当前生成器”替代事实验证。

**版本维护约定：**v2 已集成本地 `main`；是否正式发行以精确 git tag 与 GitHub Release 为准。此前草案页可以离线阅读，但没有“任意后续插件都能校验旧 v2 草案”的承诺，应使用产生它的插件提交校验，或从原始 JSON 重新生成。正式接受某个格式后，凡改变可见模板、派生事实映射、CSS、JS、CSP 或完整旧记录内容的输出变更，都要升新 renderer 格式号（例如 v3），保持旧格式的受信生成/校验实现用于承诺期内的旧文档验证；用户 CLI 仍只生成最新格式，不新增第二套用户入口。纯文档/测试变更无需升格式。若不维护旧格式的校验实现，必须明确宣布该格式停止验证并提供基于原始 Trip/Journey JSON 的重渲染路径，不能让旧文件静默通过更宽的门。当前 `V207`、受信脚本对照和全页规范比较共同证明旧 v2 草案的拒绝是显式、封闭的；它们**不**证明已具备跨未来版本的 v2 验证兼容。

无 JS 时全部日程节点和完整事实记录可读，前后一天及试探按钮由 CSS 隐藏；启用受信 JS 后只切换所选日、显示局部预计算后果和撤回，不写输入或持久化。按钮的 JS-ready 显示选择器排除 `[hidden]`，并显式隐藏该状态，因为 [HTML 标准](https://html.spec.whatwg.org/multipage/interaction.html#the-hidden-attribute)说明作者 CSS 的 `display` 规则可覆盖 `hidden` 效果。试探仅允许未锁定、无真实车次的 `static`/`mock` 草案交通，排除未生效/自由时段、异组同时出发的交通以及跨日安排；半开区间交集同时记录原草案已有重叠和试算后总重叠。没有来源依据的车次、票价或后续重排不推断。

## Acceptance and boundaries

2026-09-24，提交 `f493f4f403f808ede8460e262dbf6682ec0aaab7` 的候选实现在限定合成样本上完成独立体验验收：3 天 Trip、16 天 Journey 的中英界面，1440 桌面和 390 模拟移动视口、切日与局部试算/撤回、键盘焦点、无 JS 阅读，以及中文 A4/Letter 打印的完整来源、时间图和导航。运行画面、操作记录与 PDF 由用户提供；验收方独立审阅原始产物和源数据，没有亲自驾驶浏览器。真实触控设备、全部浏览器，以及浏览器网络/控制台/CSP 执行探针没有通测或重跑；不据此宣称全量 CI 或跨浏览器通过。

此 ADR 记录**经独立验收且已集成本地 `main` 的 v2 实现**；本地提交和本 ADR 本身不充当推送、发布或安装凭证，**不替换 v1 已接受合同的历史含义**。它不修改 Trip/Journey schema、provider 或 planner。远端正式发布与本机安装须分别以精确标签／Release 和安装校验回执核对；若后续撤回 v2，CLI 输出版本切回 v1，旧 validator 与 JSON 无需迁移。
